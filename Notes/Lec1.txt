Why we need docker ?? 
- reason is that one ml application working on some one's lets say A device but failed in another let's say B 
        ->  possible reason's be different python versions 
        -> missing python packages or there version 
        -> different OS Dependencies

so  in what terms docker gonna help .....
SO Docker helps package your application code, runtime, dependencies, and startup 

4 major requirements 
        - Dockerfile - Instructions for packaging the ML application
        - Image - packaged reusable application artifact
        - container - Running instance of that image
        - port mapping -makes the api inside the container accessible from your system 

Commands for docker
1. docker ps _> print all running containers
2. docker ps -a _> print active or non-active containers
3. docker ps -t <name_of image> .

Note - every thing will be shared will be image 

.dockerignore - file where you dont want to put unwanted files as a image 

docker images - list all images
5. start the container
   docker run -d --name ml-api -p 8000:8000
   -d for detach when not want logs in termainal of vs code 
   name of container must not have space
   first port for locally and second for docker

What is CI/CD?
CI - Continous Intigeration: Automatically code changes through test and build checks 
CD - Continous Delivery : Keeps changes ready for release , with production release potentially requiring approval 
CD - Continous Deployement : Automatically release changes to production when all required check pass 

Automated Testing
    -Automated testing catches issues before a changes move to production
    -pytest + fastapi test client + github actions
